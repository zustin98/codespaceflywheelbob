# Guide 1 – Créer ton compte GitHub

⏱️ Environ 10 minutes. Idéalement **à la maison, avant la séance 1**, avec un parent.

## C'est quoi, GitHub ?

**GitHub** est un site web où les programmeurs du monde entier rangent leur code. C'est un peu
comme un Google Drive pour le code, mais en plus intelligent : il garde **l'historique** de
toutes tes modifications. Tu peux donc toujours revenir en arrière si tu fais une erreur.

Les équipes FRC s'en servent toutes pour partager le code de leur robot.

## ⚠️ Avant de commencer

- **Tu dois avoir au moins 13 ans** pour créer un compte GitHub (c'est la règle de GitHub).
  Si tu as moins de 13 ans, pas de souci : tu vas travailler **en équipe avec un ou une
  partenaire** qui a un compte. Parles-en à ton animateur ou ton animatrice.
- **Demande la permission à un parent** avant de créer un compte sur un site web.
- Utilise une **adresse courriel que tu peux consulter** (celle de l'école si ton
  animateur te le demande). Tu vas recevoir un code par courriel.
- **Choisis un nom d'utilisateur sans ton nom de famille complet.** Exemple :
  `alex-robot-2026`, `sam-frc-codeur`. Il sera visible publiquement.

## Étape 1 : aller sur GitHub

1. Ouvre **Chrome** sur ton Chromebook.
2. Va à l'adresse **https://github.com**.
3. Clique sur le bouton **Sign up** (« S'inscrire »), en haut à droite.

> 🌐 Le site de GitHub est en anglais. Ce guide t'indique chaque bouton en anglais **en gras**,
> avec sa traduction en français.

## Étape 2 : remplir le formulaire

GitHub te demande, dans l'ordre :

| Champ (en anglais) | Ce que tu écris |
|---|---|
| **Email** | Ton adresse courriel |
| **Password** | Un mot de passe solide : au moins 15 caractères, **ou** au moins 8 avec un chiffre et une lettre minuscule. Une petite phrase marche très bien, ex. `MonRobotLance3Ballons!` |
| **Username** | Ton nom d'utilisateur (voir les conseils plus haut) |
| **Your Country/Region** | Ton pays |

Puis clique sur **Continue** (« Continuer ») ou **Create account** (« Créer le compte »).

> 🔐 **Écris ton mot de passe dans un endroit sûr** à la maison. Ne le donne jamais à un ami.

## Étape 3 : prouver que tu n'es pas un robot 🤖

GitHub te montre un petit casse-tête (par exemple : choisir la bonne image). Suis les
instructions à l'écran. C'est drôle de prouver qu'on n'est pas un robot quand on veut
programmer un robot !

## Étape 4 : entrer le code reçu par courriel

1. Va voir tes courriels. Tu as reçu un message de GitHub avec un **code de 8 chiffres**
   (*launch code*).
2. Tape ce code dans la page de GitHub.

> ❓ **Pas de courriel ?** Attends 2 minutes et regarde dans le dossier **Courrier
> indésirable** (spam). Certaines adresses d'école bloquent les courriels de l'extérieur :
> dans ce cas, utilise une autre adresse avec l'accord de ton parent ou de ton animateur.

## Étape 5 : te connecter

1. Clique sur **Sign in** (« Se connecter »).
2. Entre ton nom d'utilisateur (ou ton courriel) et ton mot de passe.
3. Si GitHub te pose des questions sur toi (« *What do you plan to use GitHub for?* »), tu
   peux cliquer sur **Skip personalization** (« Passer ») en bas de la page.

🎉 **Bravo, ton compte est créé !**

## Étape 6 (plus tard) : la double authentification (2FA)

Un jour, GitHub va te demander d'activer la **double authentification** (*two-factor
authentication*, ou **2FA**). C'est une deuxième serrure sur ton compte : en plus du mot de
passe, il faut un code qui change toutes les 30 secondes.

- Fais-le **avec un parent**, avec une application comme *Google Authenticator* ou
  *Microsoft Authenticator* sur son téléphone ou le tien.
- GitHub va te donner des **codes de récupération** (*recovery codes*). **Imprime-les ou
  écris-les sur papier et garde-les à la maison.** Sans eux, si tu perds le téléphone, tu
  perds ton compte !
